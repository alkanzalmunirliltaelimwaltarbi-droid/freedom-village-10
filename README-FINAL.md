# برنامج خدمات قرية الحرية — الإصدار النهائي V7

هذا الإصدار مخصص للنشر كـ PWA على GitHub Pages مع مزامنة Supabase.

## قبل النشر
1. نفّذ الملف `supabase/INSTALL-FINAL.sql` مرة واحدة داخل SQL Editor في مشروع Supabase.
2. لا ترفع ملف `ADMIN-CODES-PRIVATE.txt` إلى مستودع GitHub عام.
3. ارفع بقية ملفات المشروع إلى جذر مستودع GitHub بحيث يكون `index.html` في الجذر.
4. فعّل GitHub Pages من فرع `main` ومجلد `/ (root)`.

## أكواد البداية
الأكواد الفعلية موجودة فقط في `ADMIN-CODES-PRIVATE.txt`. قاعدة البيانات تخزن SHA-256 فقط.

## ملاحظات أمنية
- مفتاح Supabase المستخدم في `config.js` هو مفتاح publishable/anon وليس service-role.
- لا تضع أبداً مفتاح service-role أو أي secret في GitHub أو داخل JavaScript.
- صلاحيات البيانات الحساسة تتم عبر RPCs مع التحقق من جلسة الدخول والدور.
- الجلسة صالحة 30 يوماً وتخزن رمز جلسة عشوائياً في الجهاز.

## الوظائف التي تم تضمينها
الرئيسية، الأخبار، الصلاة، الخدمات، الطوارئ، الشكاوى، المقترحات، الفعاليات، دليل القرية، عن المنصة، لوحة المشرف، إدارة المحتوى، إدارة أوقات الصلاة، تحديث حالات الشكاوى والمقترحات، ومزامنة Supabase.

## اختبار النشر
بعد النشر افحص:
- `/index.html`
- `/manifest.webmanifest`
- `/sw.js`
- `/assets/icon-192.png`
- `/assets/icon-512.png`
- `/assets/freedom-village-logo.png`

ثم افتح الموقع مباشرة في Chrome على HTTPS. قد يستغرق GitHub Pages عدة دقائق حتى تظهر التغييرات.


## أمان رموز الدخول
رموز الدخول الفعلية لا توضع داخل حزمة النشر العامة. ملف رموز المشرفين محفوظ خارج هذه الحزمة.
قاعدة البيانات تحتوي على SHA-256 للرموز فقط، بينما ملف الواجهة يستخدم مفتاح Supabase publishable فقط.
